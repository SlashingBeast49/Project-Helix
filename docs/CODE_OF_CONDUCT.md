# Code of Conduct

## Our Pledge

Project Helix is committed to creating a welcoming, respectful, and inclusive community.

## Expected Behavior

- Be respectful.
- Be constructive.
- Be open to feedback.
- Support learning.
- Credit others' work.

## Unacceptable Behavior

- Harassment
- Personal attacks
- Discrimination
- Trolling
- Plagiarism
- Publishing false scientific information intentionally

## Scientific Integrity

Project Helix prioritizes:

- Transparency
- Reproducibility
- Accurate citation
- Honest reporting of results

If you are unsure about data quality or methodology, please open an Issue before making assumptions.

## Enforcement

Maintainers may remove contributions or restrict participation if this Code of Conduct is violated.

Let's build something useful together.
