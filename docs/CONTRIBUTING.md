# Contributing to Project Helix

Thank you for your interest in contributing to Project Helix!

## Ways to Contribute

- Report bugs
- Suggest new features
- Improve documentation
- Improve data quality
- Add visualizations
- Optimize code
- Improve machine learning models

## Before You Start

Please:

- Check existing Issues and Pull Requests.
- Open an Issue before making major changes.
- Keep pull requests focused on one feature or fix.

## Coding Standards

- Follow PEP 8 for Python.
- Write clear, well-documented code.
- Add comments where necessary.
- Keep notebooks clean and reproducible.

## Data Standards

Project Helix values scientific accuracy.

- Never fabricate data.
- Cite all data sources.
- Document any preprocessing.
- Explain missing values.

## Commit Messages

Examples:

feat: add ionization energy dataset

fix: correct atomic radius units

docs: update README

## Thank You

Every contribution, no matter how small, helps improve Project Helix.
